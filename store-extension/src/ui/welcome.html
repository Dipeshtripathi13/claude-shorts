Tangent is installed

Short explainer videos for whatever you just asked your AI assistant.

How it works

When you send a message to Claude or ChatGPT, Tangent reads that one message locally and works out what it is about. If there is a concept worth explaining, a Find explainers button appears in the panel.

Nothing is searched, and nothing leaves your browser, until you click that button. A message you ignore costs nothing and goes nowhere.

Two things to do

  1. Add a YouTube API key. Tangent searches with your own key, so nothing is routed through anyone else's server.
  2. Open a chat and click the Tangent icon in your toolbar to show the panel. Pin the icon so it is easy to reach.

Already had a chat tab open? Reload it once — browsers do not add extensions to pages that were already loaded.

What Tangent reads

Only the message you just typed, on claude.ai, chatgpt.com and chat.openai.com. Not the replies, not your history, not any other site.

Before anything is searched, code, file paths, URLs, email addresses and anything shaped like a password or API key are stripped out. If a message looks like it contains a credential, Tangent drops it entirely and offers nothing.

What reaches YouTube is a short phrase such as database migration postgres explained — never your message.
