YouTube API key

Tangent searches with your own key. Nothing is routed through anyone else's server, and your quota is yours alone.

  1. Open the Google Cloud console and create a project.
  2. Enable YouTube Data API v3.
  3. Under Credentials, create an API key and paste it below.

Google grants 100 searches per day per project. Tangent stops at 90 to leave you headroom, and reuses saved results so the same topic never costs twice.

When to offer

Higher means fewer buttons, and only for clear concepts. Lower means more, including vaguer ones.
